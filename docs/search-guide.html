Philm / field guide

Two ways to find footage

Valid as of: 2026-10-27

The main page and Discover are separate searches. They look at different information, so a query can return different clips on each page.

Main page · Corpus

Search the written record

Finds words in Philm's video database: filenames, paths, and descriptions. It is useful when you know a name or when someone has already described the scene.

You type words → Philm matches stored text → video records
Discover

Search the footage itself

Turns your description into an EmbeddingGemma vector and compares it with saved vectors made from video proxies. It can find visual similarities without a written label.

You describe a scene → Philm compares vectors → ranked video windows

One query, two outcomes

“rain on a windshield at night”
CorpusFinds videos whose stored path, filename, or description contains matching words. An unlabeled rainy clip may be missed.
DiscoverRanks indexed windows whose visual content resembles the description, even if their filenames are meaningless.

Discover's similarity number tells you relative closeness within this index. It is not a probability that the description is true. Open the result and judge the footage yourself.

Where to start

Use Corpus for known clips and recorded metadata. Use Discover when you are looking for an image, gesture, setting, or visual texture. Run uv run vanalyze ui in the Philm repository first.

Current boundary: Discover searches every clip that has a proxy (5,625 of 5,627). The merged index has no capture dates yet, so every result reads "date unknown" and links to its proxy rather than the original. Its video vectors were made from 360p proxies; retrieval quality against originals still needs a direct comparison.

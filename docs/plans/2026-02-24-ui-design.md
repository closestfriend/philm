# Philm UI — Design

**Date:** 2026-02-24
**Status:** Approved

## Summary

Local web app launched via `vanalyze ui`. FastAPI serves both the API and an HTMX frontend. No build step, no Node. The existing SQLite archive is the data layer.

## Architecture

```
vanalyze ui
└── FastAPI (localhost:8000)
    ├── /              → corpus browser (HTMX)
    ├── /video/{id}    → clip detail + player
    ├── /api/analyze   → trigger analysis jobs
    ├── /api/ingest    → file drop / folder scan
    └── /api/stream    → SSE for analysis progress
```

The UI is a new subcommand added to the existing Typer CLI. FastAPI runs in-process via `uvicorn`. Jinja2 templates serve HTMX fragments. The existing `archive.py` is the sole data layer — no new database.

## Corpus Browser (`/`)

Card grid of all ingested clips. Each card shows:

- **Thumbnail** — extracted via ffmpeg on ingest
- **Description** — `video_description` field (present on all analyses) as primary text
- **Framework coverage strip** — 14 pills, one per philosophical mode + sizzle. Filled = analysis done, hollow = not run. Clicking a hollow pill triggers that analysis.
- **Duration + filename**

**Filtering:** By framework coverage ("show clips with Baudrillard done"). Full-text search over descriptions via SQLite FTS.

**Intake:** Two entry points on the corpus page:
- Drop zone — drag video files directly
- Folder path input — scans recursively, adds all found videos

On ingest: extract thumbnail, run `--paragraph` for `video_description`, register in archive.

## Clip Detail + Player (`/video/{id}`)

Video player at top. Analysis panel below (side-by-side on wide screens).

### Overlay Mode (toggleable)

Timecode-synced analysis over the video. As playback progresses, the relevant moment surfaces as an overlay — framework name, key fields (intensity, gaze type, etc.), description text. Fades in/out at timecode boundaries. Works for all completed framework analyses simultaneously, or filtered to one.

### Panel Mode

All timecodes listed chronologically. Clicking a timecode seeks the video to that moment.

## Analysis Jobs

Triggered from the coverage strip in the corpus browser or clip detail view. Run server-side. Progress streamed back via SSE — the pill animates while running, fills on completion. No page reload.

## Styling

- Dark background (footage reads better)
- Monospace type for analysis text (preserves terminal DNA)
- No decorative chrome
- HTMX partial page swaps — interactions feel snappy without SPA complexity
